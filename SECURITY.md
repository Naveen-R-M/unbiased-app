# Security Policy

Please do not report security vulnerabilities in a public issue or pull
request.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected version, impact, reproduction steps, and any proposed
mitigation. If private vulnerability reporting is not available, contact a
Circuit & Chisel organization owner privately before disclosing the issue.

Security fixes are made against the latest release and the current
`main` branch. Older versions may not receive separate fixes.
